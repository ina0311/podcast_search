# デプロイコマンド

このコマンドは、完全なデプロイガイドに従ってデプロイを実行します。

## 使用方法

```
@docs/DEPLOYMENT_GUIDE.md に従ってデプロイを実行してください
```

または

```
デプロイガイドのステップ X を実行してください
```

## デプロイガイドの場所

- 完全ガイド: `docs/DEPLOYMENT_GUIDE.md`
- 簡易版: `docs/deployment.md`
- コマンド一覧: `infra/aws/DEPLOY_COMMANDS.md`

## エージェント向けの指示

デプロイを実行する際は、`docs/DEPLOYMENT_GUIDE.md` を参照してください。このドキュメントには以下が含まれています:

1. **コマンド実行可能なステップ**: エージェントが直接実行できるコマンド
2. **手動操作が必要なステップ**: ユーザーに依頼する必要がある操作
3. **確認事項**: 各ステップでの確認ポイント
4. **トラブルシューティング**: よくある問題と解決方法

各ステップには「**エージェント**:」というプレフィックスで、エージェントが実行すべき操作が明記されています。

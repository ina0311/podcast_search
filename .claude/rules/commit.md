# コミット規約

## 分割方針

コミットは論理的な単位で分割する。1 コミット = 1 つの意図。

| 状況 | 分割の目安 |
|------|-----------|
| 機能追加 + ドキュメント更新 | 2 コミット |
| 複数のバグ修正 | バグごとに分割 |
| リファクタリング + 機能変更 | 2 コミット（リファクタ先行） |
| 設定変更 + コード変更 | 2 コミット |

分割が不明な場合は `git diff --stat` で変更ファイルを確認し、関心事ごとにグループ化する。

## 実行

コミットを作成する際は必ず `.claude/skills/commit/SKILL.md` の手順を使うこと。
